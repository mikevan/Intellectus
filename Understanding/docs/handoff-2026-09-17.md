## Rules now in force, all from his rulings

- **Sequencing:** no change to `src` or `scripts` between the measured run and the appended `EXPECTED.json` row, not even a display-only change. C-2's rows carry a build id that no longer exists because this rule did not exist yet; it stays as recorded.
- **Encoder versions describe that encoder's behaviour.** A Python bump with zero measured movement is correct; a project-wide bump is not.
- **A classification step never buys a label with a represented fact.** Monotonicity is tested at the projection level.
- **`ir_schema` versions structure and semantics of the contract.** Widening a closed vocabulary keeps the schema; a new expression or statement kind moves it. Consumers must not assume `ir_schema` alone identifies the category vocabulary (recorded finding, unsolved).
- **Legacy vocabulary is kept, never emitted.** `completion-dependency` stays in `OPAQUE_CATEGORIES` for schema-5 readers; a test asserts schema-6 adapters never produce it.
- **Provenance is not semantics.** The await point's `at` is on the projected outcome and excluded from the fingerprint (`withoutProvenance`). X2 caught the leak.
- **Predictions are scored as written before anything is corrected.** Failures and unpredicted findings are logged as such.

- **The residual `declaration` category** holds imports and class definitions; toml's last member is a nested class. Needs its own revisit. A decorated nested `def` is still `declaration`.

- **Module-level names are not modelled.** `ready` in `loadLanguage` encodes as `unknown`; the statement is represented, the operand is not identified.
- **Statements outside any encoded function** (radon 224, ir0-typescript 117 plus 14 in arrow functions) are a separate population the adapters never encode.
