# User guide

## Investigating an existing application
1. Define the application's boundary, supported inputs, externally observable behavior and environment.
2. Identify the linguistic adapters and lexicons applicable to the application.
3. Acquire evidence and candidate semantic claims through independent specialists.
4. Resolve or retain uncertainties and contradictions; review the temporal ontology and its scope.
5. Choose an implementation target and separately specify deployment constraints.
6. Generate an implementation and independently validate it against the observation contract.

This is the intended workflow; the full end-to-end flow has not been established for arbitrary applications.

## Starting from a semantic model
Author purpose, actors, events, state transitions, conditions, effects, exceptions and acceptance criteria. Review ambiguous requirements before generation. See [semantic-first development](semantic-first.md).

## Reading results
A verified claim applies only within its recorded scope. Unknown semantics must remain visible. Do not equate a model's confidence, consensus or matching structural hash with proof.
