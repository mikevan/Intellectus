# Glossary

| Term | Meaning |
|---|---|
| Semantic flow | Meaningful events, transformations, conditions and effects over time |
| Temporal ontology | Concepts and relationships represented with time, state or event context |
| Understanding | Retained semantic knowledge and supporting evidence |
| Linguistic adapter | Language-aware interpretation and expression service |
| Lexicon | Scoped reusable domain or framework knowledge |
| SLM | Small language model |
| LoRA | Low-rank adaptation for model training |
| Colibri | Model inference service boundary |
| Oracle | Independent reference for expected outcomes |
| Semantic identity | Equivalence under a defined observable contract |
| Structural IR | Intermediate representation of implementation structure |
| OSGi | Modular service lifecycle framework used by Karaf |
