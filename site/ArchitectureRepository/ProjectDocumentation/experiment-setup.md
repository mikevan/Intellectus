# Set up the Intellectus experiment environment

Install the shared tools once, then follow the run instructions for the experiment you want to reproduce.

- [Windows 10/11 environment setup](experiment-setup-windows.md)
- [macOS and Linux environment setup](experiment-setup-mac-linux.md)
- [Experiment run instructions](experiment-runs.md)

| Experiment | Components |
| --- | --- |
| RT-1 | Python, Node.js, npm, Understanding, Complexity |
| RT-2 through RT-4 | RT-1 tools for verification. Fresh OSGi lifecycle replay also requires JDK 17, Karaf 4.4.13, and the original experiment bundles and configuration. |
| P1/P2 | Python and Node.js |
| Phase I live trials | Python, Node.js, Understanding, and Colibri |
| P3 and P4 | Python for preflight. Colibri for live requests. |
| RT-5 | Draft. See its protocol for prerequisites and approval gates. |
