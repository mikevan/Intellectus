## Runtime prerequisites
The reported historical Karaf prototype used Java 17 and Karaf 4.4.13. Python and Node/TypeScript tooling were used for the restricted experiments. These are historical observations, not a supported-version matrix for a public release. Check the actual checkout's build descriptors, dependency locks and documented experiment prerequisites.

## Install and run
No verified public distribution or universal installation command is asserted here. Select a tagged release when one is documented, verify the source checksum, and follow its release-specific build/run instructions. For a research checkout, record the commit, tool versions and configuration; build according to the repository's actual module instructions; run the selected frozen protocol in a fresh evidence directory. Do not substitute illustrative examples for executable test evidence.

See [downloads and compatibility](downloads.md).
