# Downloads and release compatibility

## Releases
This documentation edition does not establish a downloadable Intellectus release. Once a release has been qualified, publish source archive, checksum, signature if available, release notes, dependency prerequisites, installation instructions and evidence manifest in the repository's release area.

| Item | Historical experiment configuration | Supported release status |
|---|---|---|
| Karaf | 4.4.13 reported | To qualify |
| Java | 17 reported | To qualify |
| Python and TypeScript | Restricted round-trip adapters | Version and construct matrix to qualify |
| Colibri | Interface inventoried | Serving compatibility to qualify |

## Approval
Record a release candidate and immutable source revision, test gate results, known limitations, license/dependency inventory, reviewer decisions and checksums. Distinguish snapshots from reviewed releases. Users should not be told that experimental code is production-qualified.
