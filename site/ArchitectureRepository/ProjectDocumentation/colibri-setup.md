# Set up Colibri for local inference

Choose the guide for your platform. Both cover installing the runtime and checkpoint, checking model readiness, and testing inference.

- [Windows 10/11 setup](colibri-windows.md)
- [macOS and Linux setup](colibri-mac-linux.md)

Colibri is used for the live AI experiments. P1/P2 and the deterministic preflights run without it. See the [Developer Guide](developer-guide.md) for the P3 and P4 trial commands and scoring instructions.
